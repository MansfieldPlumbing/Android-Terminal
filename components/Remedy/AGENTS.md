# Agent Guidelines and Rules

All autonomous and human contributors working on the Remedy repository must adhere strictly to the following rules:

- Work on exactly one invariant per branch.
- Execute exactly one semantic objective per commit.
- Allow no modification outside the explicitly allowed file list for a task.
- Make no test edits merely to make implementation pass.
- Allow no ignored timeout or return code.
- Make no source or report claim without an executable assertion.
- Stop and request review when a fix changes approved semantics.
- Never push directly to main.
- Never force push.
- Never amend the recovered baseline commit or tag.
